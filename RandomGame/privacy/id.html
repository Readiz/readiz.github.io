1. Informasi permainan yang diproses di perangkat

Kamu dapat bermain tanpa mendaftar atau masuk. Posisi sentuhan, nomor pemain, karakter, dan hasil pertarungan diproses di memori perangkat selama permainan berlangsung dan tidak dikirim ke server pengembang. Progres permainan tidak disimpan setelah proses aplikasi berakhir.

2. Pengumpulan dan pembagian data di aplikasi Google Play

Versi Google Play berjalan offline tanpa izin internet. Aplikasi ini tidak menyertakan SDK iklan, analitik, atau pembayaran dan tidak mengumpulkan, mengirim, atau membagikan data pribadi maupun pengenal perangkat. Google Play mengelola pemasangan dan pembaruan; kebijakan privasi layanan tersebut berlaku untuk proses itu.

3. Izin perangkat

Permainan menggunakan getaran untuk menandai pemain yang bergabung dan hasil pertarungan. Aplikasi tidak meminta akses kamera, mikrofon, lokasi, kontak, atau penyimpanan eksternal. Hanya APK yang didistribusikan langsung yang menambahkan izin internet untuk memeriksa pembaruan dan izin membuka pemasang APK pilihanmu.

4. Penyimpanan informasi

Pengembang tidak menyimpan akun atau riwayat permainan di server.

5. Versi web

Versi web meminta halaman dan aset melalui server hosting. Sentuhan dalam permainan, informasi peserta dan hasil pertandingan diproses di memori perangkat, tanpa dikirim atau disimpan di server pengembang. Pengaturan bahasa dan suara disimpan di browser tersebut. Kamu dapat menghapusnya dengan menghapus data situs pada browser.
